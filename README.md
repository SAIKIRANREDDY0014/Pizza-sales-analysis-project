# 🍕 Pizza Sales Data Analytics Project

## 📌 Project Overview

This project focuses on analyzing pizza sales data using Microsoft SQL Server and Power BI to identify key business insights, sales trends, and product performance.

SQL queries were written to calculate business KPIs and answer important business questions. Power BI was used to create interactive charts and visualizations for all the business queries.

## 🛠️ Tools & Technologies

- Microsoft SQL Server (SSMS)
- SQL
- Microsoft Power BI
- Data Visualization

## 📊 Key Performance Indicators (KPIs)

- Total Revenue
- Average Order Value
- Total Pizzas Sold
- Total Orders
- Average Pizzas Per Order

## 🔍 Business Analysis

- Daily Trend for Total Orders
- Monthly Trend for Orders
- Percentage of Sales by Pizza Category
- Percentage of Sales by Pizza Size
- Total Pizzas Sold by Category
- Top 5 Pizzas by Revenue
- Bottom 5 Pizzas by Revenue
- Top 5 Pizzas by Quantity
- Bottom 5 Pizzas by Quantity
- Top 5 Pizzas by Total Orders
- Bottom 5 Pizzas by Total Orders

## 📈 Project Deliverables

- SQL queries for business analysis.
- KPI calculations using SQL.
- Interactive Power BI dashboard.
- Charts and visualizations for all business queries.
- Sales performance insights.

## 🎯 Key Learnings

- Writing SQL queries for business analysis.
- Calculating business KPIs.
- Using aggregate functions, joins, subqueries and filtering.
- Analyzing sales trends and product performance.
- Creating interactive dashboards and visualizations using Power BI.
- Converting raw sales data into meaningful business insights.
